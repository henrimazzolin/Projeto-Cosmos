# Projeto Cosmos

Nosso projeto é um jogo sobre lixo espacial chamado **Operação Órbita Limpa**.

A ideia é controlar uma nave e limpar os lixos que ficam na órbita da Terra, como partes de foguetes, satélites quebrados e outros pedaços que ficam viajando pelo espaço. Além do jogo, também queremos mostrar um pouco sobre esse problema, porque muita gente nem sabe que existe lixo espacial ou que ele pode causar acidentes.

O jogo ainda está sendo feito, então várias coisas podem mudar durante o desenvolvimento.

## Como vai ser o jogo

O jogador vai controlar uma nave, desviar dos obstáculos e usar um disparo para coletar ou destruir os detritos. O jogo vai ter três partes: órbita baixa, órbita média e Campo Kessler. Cada parte vai ter um cenário e lixos diferentes.

Os controles que pensamos até agora são:

- W ou seta para cima: subir;
- S ou seta para baixo: descer;
- espaço: usar o pulso de coleta;
- tecla E: usar a habilidade da nave.

Eu vou ficar responsável por desenvolver o jogo. Vou fazer as telas, o menu, os controles da nave, os disparos, os detritos, as colisões, a pontuação, a vida do jogador, as fases e o funcionamento geral do projeto.

No final, vou juntar as partes que forem feitas pelo grupo e conferir se o jogo está funcionando.

Ele também vai preparar a parte de mostrar o jogo, escolher quais telas e funções serão apresentadas e combinar o que cada pessoa vai falar. Antes da entrega, ele vai revisar os slides e ajudar o grupo a ensaiar.

O Guilherme vai fazer as pesquisas usadas no trabalho. Ele vai procurar informações sobre o que é lixo espacial, como esse lixo é criado, quais problemas ele pode causar, o que é o efeito Kessler e o que já está sendo feito para diminuir esse problema.

Antes da entrega, ele vai revisar a documentação e conferir se não está faltando nenhuma etapa importante.

## Arquivos do projeto

- `index.html`: tela principal;
- pasta `css`: aparência do jogo;
- pasta `js`: programação;
- pasta `assets`: imagens;
- pasta `audios`: músicas e efeitos sonoros.

Para abrir o projeto, é só baixar a pasta e abrir o arquivo `index.html` no navegador.

Por enquanto é isso. Conforme o jogo for avançando, vamos atualizando este arquivo.
